### Usage

all stickers are served via [jsdelivr CDN](https://www.jsdelivr.com/).

```
https://cdn.jsdelivr.net/gh/Clionyx00/onyxkawii-stickers@main/stickers/<filename>
```

filenames are CDN-safe (lowercase, hyphens, no special characters). display names are preserved in this readme.
