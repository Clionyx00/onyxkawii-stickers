### Usage

All stickers are served via [jsdelivr CDN](https://www.jsdelivr.com/).

```
https://cdn.jsdelivr.net/gh/Clionyx00/onyxkawii-stickers@main/<filename>
```

Filenames with special characters need URL encoding (spaces → `%20`, etc.).
